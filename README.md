# genesis-runtime
Genesis is a modular runtime for building agentic systems.  It is intentionally minimal, framework-agnostic, and designed for interoperability with existing AI ecosystems rather than replacing them. Every capability is a plugin. Every workflow is composable. Build anything from a tiny coding assistant to an autonomous business.

In this repository you will find the runtime, and eventually a library collection of plugins, documentation, and developer guides.

Compatible with Nova plugins, though additional supporting plugins will be needed for some to function correctly.

Stay tuned as I organise this.
